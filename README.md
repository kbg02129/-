# CapCut 에이전트

영상을 넣으면 **무음 구간**과 **버벅거린 부분**(추임새, 말더듬, 반복, 다시 말하기)을 자동으로 잘라내고
**자막(SRT)** 까지 만들어 주는 도구입니다. 결과물은 CapCut에 바로 가져와서 이어서 편집할 수 있습니다.

```
원본.mp4 ──▶ 무음 감지 (ffmpeg)
         ──▶ 음성 인식 (Whisper, 단어 단위 시간)
         ──▶ 버벅임 감지 (규칙 + 선택적으로 Claude 검토)
         ──▶ 컷 편집된 영상.mp4  +  자막.srt  +  edit_plan.json
```

## 설치

```bash
brew install ffmpeg                    # macOS (Windows: winget install ffmpeg)
pip install -e ".[all]"                # faster-whisper + anthropic 포함
```

## 사용법

```bash
capcut-agent 내영상.mp4
```

`내영상_capcut/` 폴더에 다음이 생깁니다.

| 파일 | 설명 |
|---|---|
| `내영상_edited.mp4` | 무음·버벅임을 잘라낸 영상 |
| `내영상.srt` | 편집된 영상 기준으로 시간이 맞춰진 자막 |
| `transcript.json` | 음성 인식 결과 (다음 실행 때 `--transcript` 로 재사용하면 빠름) |
| `edit_plan.json` | 어디를 왜 잘랐는지 기록 |

### CapCut에서 불러오기

1. CapCut PC/웹에서 새 프로젝트 → `내영상_edited.mp4` 가져오기
2. **텍스트 → 자막 → 자막 가져오기(Import captions)** 에서 `내영상.srt` 선택
3. 자막이 수정 가능한 텍스트로 들어오므로 CapCut에서 글꼴·스타일을 입히면 끝

CapCut 모바일처럼 SRT를 가져올 수 없는 환경이면 `--burn` 으로 자막을 영상에 입혀서 출력하세요.

## 자주 쓰는 옵션

```bash
capcut-agent 영상.mp4 --dry-run              # 렌더링 없이 무엇이 잘릴지만 확인
capcut-agent 영상.mp4 --llm                  # Claude가 NG·다시 말하기·오타까지 검토
capcut-agent 영상.mp4 --burn                 # 자막을 영상에 입혀서 출력
capcut-agent 영상.mp4 --model small          # 빠른 음성 인식 (정확도는 낮아짐)
capcut-agent 영상.mp4 --transcript 영상_capcut/transcript.json   # 음성 인식 건너뛰고 재편집
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--noise-db` | `-35` | 이 크기(dB) 이하를 무음으로 판단. 배경 소음이 크면 `-30` 정도로 올리기 |
| `--min-silence` | `0.6` | 이 길이(초) 이상의 무음만 자름. 템포를 빠르게 하려면 `0.4` |
| `--keep` | `0.15` | 무음을 자를 때 앞뒤로 남기는 여유(초). 말이 뚝 끊기면 늘리기 |
| `--keep-repeats` | 꺼짐 | 반복·다시 말하기는 두고 추임새만 자르기 |
| `--fillers` | `음,어,으,...` | 추임새 목록 직접 지정 (예: `--fillers 음,어,그니까,약간`) |
| `--no-silence` / `--no-disfluency` | | 무음 컷 / 버벅임 컷 끄기 |
| `--max-chars` | `18` | 자막 한 줄 최대 글자 수 (쇼츠는 `12` 정도 추천) |

## 버벅임을 어떻게 찾나요?

- **추임새**: "음", "어", "으음" 같은 소리 단어
- **반복**: "저는 저는" → 앞의 "저는" 삭제 (중간에 추임새가 끼어 있어도 인식)
- **다시 말하기**: "오늘은 영상을 … 오늘은 영상을 찍어요" → 앞의 실패한 시도를 삭제
- **말더듬**: "그래 그래서" → 앞 조각 삭제
- **`--llm` (Claude)**: 위 규칙으로 못 잡는 NG("잠깐만, 다시 할게요"), 문장을 바꿔 다시 말한 부분,
  음성 인식 오타를 문맥으로 판단합니다. 규칙 감지 결과를 참고용 힌트로 함께 보냅니다.
  `ANTHROPIC_API_KEY` 환경변수가 필요합니다.

Whisper는 원래 추임새를 지우고 받아쓰는 경향이 있어서, 추임새가 섞인 예시 문장을 프롬프트로 줘서
들리는 그대로 받아쓰도록 유도합니다.

## 한계

- CapCut은 외부에서 타임라인(컷 목록)을 불러오는 공식 기능이 없고, 최신 버전은 프로젝트 파일을 암호화합니다.
  그래서 CapCut 프로젝트를 직접 만드는 대신 **이미 잘린 영상 + SRT** 를 만들어 줍니다.
  잘린 부분을 CapCut에서 되살리려면 원본에서 다시 가져와야 하므로, 먼저 `--dry-run` 으로 결과를 확인하세요.
- "정말 정말 좋아요" 같은 의도적인 반복도 잘릴 수 있습니다. 신경 쓰이면 `--keep-repeats` 나 `--llm` 을 쓰세요.
