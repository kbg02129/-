# 캡컷 에이전트 · iPad 웹

서버 없이 iPad Safari 안에서 동작하는 한 장짜리 페이지입니다.

- 브이로그 모드(기본): 초당 4프레임을 96px 로 줄여 색 히스토그램·선명도·밝기·움직임을 재고,
  오디오 음량과 합쳐 장면 점수 계산 → 색 분포가 급변하는 곳을 장면 전환으로 보고 샷을 나눔 →
  샷마다 가장 좋은 구간(기본 4초, 말소리 장면은 더 길게)을 골라 목표 길이까지 점수순으로 채움.
  어두움·흐림·흔들림 장면은 자동 제외, 장면 썸네일을 탭하면 직접 넣기/빼기
- 토킹 모드: 10ms 단위 음량(dB)으로 무음 구간 감지 후 제거
- 여러 영상: 촬영 시각(없으면 파일 시각) 순으로 정렬, ↑↓로 순서 변경. 모든 영상의 장면을 한데 모아
  점수순으로 고르고 영상 순서 → 촬영 순서대로 이어 붙임. 해상도·방향이 다르면 많이 쓰인 방향에 맞춰
  (긴 변 1920 이하) 여백으로 채우고, 오디오는 48kHz 스테레오로 변환. 오디오 없는 영상 구간은 무음으로 채움
- 컷마다 15ms 오디오 페이드로 툭 소리 방지
- 렌더링: WebCodecs(H.264 하드웨어 인코더)로 남길 구간만 이어 붙인 MP4 생성.
  브라우저에 AAC 인코더가 없으면 `@mediabunny/aac-encoder`(WASM)로 대체
- 저장: claude.ai 에서는 저장 기능, 일반 브라우저에서는 iPad 공유 시트(비디오 저장 / CapCut)

`index.html` 은 claude.ai Artifact 형식(doctype 없이 본문만)입니다.
다른 곳에 올릴 때는 `<!doctype html><html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1"></head><body>` 로 감싸서 HTTPS 로 제공하세요 (WebCodecs 는 보안 컨텍스트 필요).
